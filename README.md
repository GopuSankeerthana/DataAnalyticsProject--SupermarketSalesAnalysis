# DataAnalyticsProject--SupermarketSalesAnalysis
A data analytics project that explores supermarket sales data through interactive visualizations and dashboards. Built with Python, Pandas, Plotly, and Dash to analyze sales trends, customer behavior, product performance, and business KPIs.

## 📌 Project Overview

The Supermarket Sales Analytics Dashboard is a data analytics project that explores supermarket sales data to uncover business insights through interactive visualizations. The project uses Python-based data analysis and visualization tools to analyze sales performance, customer behavior, product trends, and revenue generation.

## 🎯 Objectives

- Analyze supermarket sales data.
- Identify sales and revenue trends.
- Understand customer purchasing behavior.
- Compare product line performance.
- Visualize key business metrics through interactive dashboards.

## 📊 Features

- Sales Trend Analysis
- Revenue Distribution Analysis
- Product Line Performance
- Customer Type Insights
- Gender-wise Purchase Analysis
- Branch-wise Sales Comparison
- Payment Method Analysis
- Interactive Visualizations with Plotly

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Dash
- Jupyter Notebook / Google Colab
